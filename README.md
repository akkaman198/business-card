# Damir — Personal Business Card

Готовый сайт-визитка для публикации через GitHub Pages.

## Что загрузить на GitHub
- index.html
- style.css
- script.js

## Публикация
1. Создай репозиторий на GitHub.
2. Загрузи эти файлы в корень репозитория.
3. Открой Settings → Pages.
4. Выбери Deploy from a branch.
5. Branch: main.
6. Folder: / (root).
7. Нажми Save.

После этого GitHub создаст ссылку на сайт.
